# 🎉 Eventora

**Eventora** is a full-stack MERN event booking platform that allows users to explore events, book tickets, and manage their bookings through a responsive and user-friendly interface.

## ✨ Features

* 🔐 User Authentication
* 🎫 Browse and explore events
* 📅 Event booking functionality
* 👤 User booking management
* ➕ Create and manage events
* 📱 Responsive user interface

## 🛠️ Tech Stack

**Frontend**

* React
* Vite
* Tailwind CSS

**Backend**

* Node.js
* Express.js

**Database**

* MongoDB

## 🚀 Installation

Clone the repository:

```bash
git clone <repository-url>
cd Eventora
```

Install dependencies:

```bash
npm install
```

Configure environment variables in a `.env` file and start the application.
